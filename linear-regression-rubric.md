# Rubric for the _linear regression_ exercises

## 1. Simpson's paradox

 - [ ] The raw data are visualized and the patterns described appropriately
 - [ ] The model without `area` is fit correctly
    - [ ] The slope and p-value are interpreted correctly
 - [ ] The model with `area` is fit correctly
    - [ ] The coefficients and p-value are interpreted correctly
 - [ ] The slope estimates and standard errors are compared in a table
 - [ ] The fitted lines from both models are visualized using correct intercepts and slopes
 - [ ] The change in the slope estimate (sign, magnitude, and uncertainty) is described correctly
 - [ ] The change is explained using a reasonable relationship between `area` and freeway distance

## 2. Fit and interpret an interactive model

 - [ ] The raw data are visualized appropriately and the patterns are described reasonably
 - [ ] The table of intercepts and slopes by area are calculated correctly
 - [ ] The additive and interactive models are fit correctly
 - [ ] Each `exide_lm` coefficient is matched to the correct $\beta$
 - [ ] The slope for each area is calculated and interpreted correctly, with units
 - [ ] The `home_age` coefficient is interpreted correctly, with units
 - [ ] The conclusions from the additive and interactive models are compared appropriately
 - [ ] The need for an interaction is explained reasonably
 - [ ] The significance of the interaction coefficient(s) is interpreted correctly in context

## 3. Simulate data for an interactive model

 - [ ] The parameter table is completed correctly, with reasonable signs and magnitudes.
 - [ ] The predictors are simulated correctly
 - [ ] The expected value includes the interaction term
 - [ ] The response is simulated correctly with normally-distributed residuals
 - [ ] The interactive model is fit correctly to the simulated data
 - [ ] The intercepts and slopes for all four lines are calculated correctly
 - [ ] The simulation is visualized appropriately, with the simulated data, lines for the simulation parameters, and lines for the fitted model.
